# Support

Thanks for using Soroban-ZK-Std. Here is where to get help.

## Questions and usage help

* **Telegram (fastest):** join <https://t.me/SorobanZKStd> and ask in the
  group. Maintainers and other contributors monitor it.
* **GitHub Discussions:** use
  <https://github.com/georgegoldman/Soroban-ZK-Std/discussions> for design
  questions, integration advice, and "how do I…" threads that are useful to
  search later.
* **GitHub Issues:** open an issue for reproducible bugs and concrete feature
  requests at
  <https://github.com/georgegoldman/Soroban-ZK-Std/issues>. Please use the
  issue templates and include your Rust version, target, and a minimal
  reproduction.

Before opening an issue, check [CONTRIBUTING.md](CONTRIBUTING.md) and the
existing issues to avoid duplicates.

## Security vulnerabilities

**Never report a vulnerability in a public issue, discussion, or pull request.**

Follow [SECURITY.md](SECURITY.md) and use GitHub's private
[Security → Report a vulnerability](https://github.com/georgegoldman/Soroban-ZK-Std/security/advisories/new)
flow. You will receive an acknowledgement within 72 hours.

## Community standards

All project spaces follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Report
conduct concerns privately to the maintainers as described there.
